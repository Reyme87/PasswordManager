## О проекте

Менеджер паролей для рабочего стола с шифрованием сетью Фейстеля. Помимо паролей приложение также предоставляет возможность сохранять данные о платёжных методах и оставлять заметки. Все сохранённые пароли/методы оплаты/заметки можно импортировать в приложение из отдельного фалйа или экспортировать для дальнейшего хранения. Приложение подходит для хранения данных в быстром доступе без опасений потерять их.

## Схема приложения

**Приложение состоит из 3-ёх главных разделов:**  
1. *Passwords*  
2. *Payment Methods*  
3. *Notes*

**Каждый раздел состоит из списка данных (пароли, платёжные методы, заметки), а также полей непосредственного отображения данных.**  
**У паролей (аккаунтов) представлены следующие поля:**  
- *Логин*  
- *Пароль*  
- *Сайт*  

<p align="center">    
  <img width="438" height="368" alt="Screenshot_3" src="https://github.com/user-attachments/assets/7f1ccd5d-a23c-4f3a-aaf8-528883be08fe" />
</p>

**У платёжных методов представлены следующие поля:**  
- *Номер карты*  
- *MmYy*  
- *CVV/CVC*  

**У заметок представлены следующие поля:**  
- *Название*  
- *Текст заметки*  

**В каждом из разделов имеются функциональные кнопки:**  
- *Add - добавление данных*  
- *Remove - удаление данных*  
- *Change - изменение данных*  
- *Import - импортирование данных (перенос из json-файла)*  
- *Export - экспортирование данных (сохранение в json-файл)*
